# 功能狀態與限制

更新日期：2026 年 11 月 15 日。這份狀態描述研究時的實測範圍，不是通用相容性保證。

## 已有實機結果

- 在測試機上，MENU＋放大鏡可召喚自製原生圖層選單。
- 觸控 LUT 開關、Film 選擇與 Close 已有成功測試，關閉後設定可保留。
- 經過修正後，曾完成每輪只按一次組合鍵即可喚醒的多輪測試，使用者回報原生控制正常。
- 曾有一張新拍 JPEG 在機內自動處理為 Kodak Gold，另存後完整讀回、解碼及雜湊驗證；原片重新讀回也一致。

## 最新一輪尚未通過的部分

最新掃描器有發現新照片，設定讀取也實際取得 `tri_x_400`。不過原生檔案命令回覆來源檔無法開啟，協調程式保留診斷資料並停止。因此，**OFF 略過與切換後自動產生 Tri-X 黑白副本仍未驗收**。

另一個工作以設定途中改變的狀態取消，不能當作濾鏡成功。最新原生開檔失敗的底層原因尚未確認，不能直接歸咎於 USB、使用者操作或照片本身。

## 目前限制

- 初次載入研究 UI 曾需要在正常拍攝畫面輕觸並放開螢幕。
- UI 有單次顯示時限；設定目前在 RAM，不能假設斷電後保留。
- UI、讀取器與 guard 必須配合確切的編譯結果、地址及版本檢查。
- 背景處理是拍攝後 JPEG 另存，不是即時取景濾鏡、RAW 改寫或影片 LUT。
- metadata 穩定等待只是候選判斷，不等於 Sony 寫檔完成通知；讀回／解碼驗證仍不可省略。
- 目前輸出使用獨立的 `A:/A6400/TEST/` 路徑，沒有宣稱已註冊到相機播放資料庫。
- 佇列有 128 個生命週期項目上限；沒有完成可無限持續拍攝的監督與回收策略。
- 尚未完成新版整合程式的 SD 冷開機驗收。
- 公開版不含上游濾鏡引擎或現成安裝包，詳見第三方來源說明。

## 故障記錄與測試界線

較早的 UI 試驗曾黑屏、卡住或令部分輸入失靈；取出電池後恢復。後續特定版本通過的短測，不能推廣成所有相機狀態都不會發生問題。

電腦端測試使用合成資料和替代 monitor，只能驗證程式邏輯、解析與失敗處理；不代表已實際呼叫 Sony 硬體或成功寫入 SD 卡。
